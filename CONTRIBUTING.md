# Contributing

1. Identify the exact problem and affected goals or categories.
2. Propose a focused change with support for new factual claims.
3. Check consistency with the canonical methodology.
4. Run python3 scripts/validate.py and bash -n setup-cerberus.sh.
5. Complete applicable QA checks.
6. Submit a pull request describing validation actually performed.

Do not commit private data or credentials. Do not describe proposed functionality as implemented. A project license has not yet been selected.
